- CCC first published CCC-1:2020, classification Public / TLP White (citable). NCA has since issued
  provider-focused editions/guidance (GCCC-CSP; a CSP edition). Taught "check NCA site for current
  version" - NO invented version assertion, NO invented domain/control counts.

  via NCA's separate CSP-implementation guidance.
- CSCC 4-2-1-1 requires critical systems hosted with CCC-compliant clouds (from CSCC public doc / hub).
