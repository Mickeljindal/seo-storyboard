No, most new SaaS products don't need Redis on day one.

Redis is a fast in-memory data store that shines at four jobs: caching expensive results, sharing sessions across servers, counting for rate limits, and brokering background jobs. Early on, a single server's memory or your existing database can cover those. Add Redis when you run more than one app server, a hot query is straining the database, you need rate limiting across instances, or you're adding background workers.
