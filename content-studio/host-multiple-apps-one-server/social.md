One server can run several apps because a light app uses a fraction of it.

Keep them clean by isolating each: its own system user, web root, process on its own internal port, environment variables, and its own database. A reverse proxy (Nginx or Apache) routes each domain to the right app. Leave headroom for spikes, never share one database across unrelated apps, and split an app onto its own server when it reliably needs most of the box.
