How to Deploy a SvelteKit App to Production the Right Way

> Pick an adapter. For a server you own, install `@sveltejs/adapter-node`, run `npm run build` to produce a `build/` directory, then run `node build` to start a real Node server (behind Nginx, kept alive by PM2). If your app is fully prerendered, use `adapter-static` instead and serve the built files like any static site with free SSL.
