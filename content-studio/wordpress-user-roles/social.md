> A standard WordPress install has five roles: Administrator, Editor, Author, Contributor, and Subscriber, in descending order of what they can do.

Multisite adds a sixth, Super Admin, which controls the whole network. Each role is a set of capabilities, and WordPress checks capabilities rather than role names, so you can add or remove individual permissions without inventing a new role. For security, grant the lowest role that lets someone finish their work, and keep the number of Administrators as small as you can.
