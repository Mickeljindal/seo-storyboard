Spin up a managed PostgreSQL or MySQL next to your app.

Put the connection in a `DATABASE_URL` environment variable, never in your code. Run your framework's migrate command (`prisma migrate deploy`, `python manage.py migrate`, `php artisan migrate`, `rails db:migrate`), then sign up a test user to confirm it sticks. On Kloudbean the database is provisioned, locked down with IP allow-listing so only your app server can reach it, and backed up for you.
