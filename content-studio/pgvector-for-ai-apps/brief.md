## Position / original value
- Founder opinion: most apps adding AI search do NOT need a separate vector database. One measured nod to Pinecone/Weaviate/Milvus/Qdrant, then land on Postgres.
- Cannot-copy angle: transactional consistency (row + embedding commit together), filter-by-column AND similarity in one SQL query, one system to run/back up. The consistency/reconciliation failure mode of the two-database setup is the anti-pattern beat.
- Real, correct SQL: CREATE EXTENSION vector; vector(1536) column; INSERT; ORDER BY embedding <=> ... LIMIT; the three distance operators; HNSW + IVFFlat CREATE INDEX with vector_cosine_ops.
