```
A Discord bot holds a live WebSocket to Discord's gateway, so it needs to run 24/7.

Put it on a small always-on server, keep the process alive with `pm2` (Node) or `systemd` (Python), and read the bot token from an environment variable, never from the code. Free tiers that sleep will keep knocking it offline. On Kloudbean you deploy from Git, set `DISCORD_TOKEN` in the console, and the platform keeps the process running and restarts it on crash or reboot.

Read the full guide: https://www.kloudbean.com/blog/discord-bot-hosting/
```
