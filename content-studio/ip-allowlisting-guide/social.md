> IP allowlisting (also called IP access control) restricts who can reach a service based on their network address.

You define allow rules for the addresses or ranges you trust and deny everything else, or the reverse, block specific bad actors and allow the rest. Ranges are written in CIDR notation, like 203.0.113.0/24 for a whole block. It is ideal for admin panels, staging environments, internal tools, and APIs that only need to be reached from known places.
