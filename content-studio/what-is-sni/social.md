what is sni

> Server Name Indication is a TLS extension that lets a client tell the server which hostname it is trying to reach, inside the first handshake message. Because the server learns the hostname before it has to present a certificate, one IP address can serve HTTPS for many different domains, each with its own certificate. Nearly every client made in the last decade sends SNI, and virtually all shared and cloud hosting depends on it.
