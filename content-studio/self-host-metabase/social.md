## LinkedIn
```
Metabase ships as a runnable Java JAR.

Run it on a managed server, but don't leave its data in the default H2 file. Back it with managed PostgreSQL as its application database (set `MB_DB_TYPE=postgres` and the rest of the `MB_DB_` vars), give the JVM a sane `-Xmx` heap, put SSL in front, and reach your data sources internally rather than over the public internet. On Kloudbean the OS, SSL, and backups come with the box; the dashboards and data stay yours.

Read the full guide: https://www.kloudbean.com/blog/self-host-metabase/
```
